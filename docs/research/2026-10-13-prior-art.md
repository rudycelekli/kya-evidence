# KYA Evidence research baseline

Verified 2026-10-13. Research depth: standard, capUsd: 2, spentUsd: null (provider/tool spend not metered). This is a build research report; it has not been accepted into an external research-memory namespace. No model evaluation calls were made during research.

## Findings

| Finding | Evidence grade | Implication |
| --- | --- | --- |
| [Open-KYA](https://github.com/open-kya/kya-standard) is v0.1.0-alpha and pre-submission/incubation | High for repository status, no evidence of standards adoption | Build complementary measured-assurance tooling; do not claim official affiliation. Its declarations do not by themselves establish behavior. |
| [W3C VC Data Model 2.0](https://www.w3.org/TR/vc-data-model-2.0/) is a Recommendation; authorization requires an accompanying framework | High for specification | Keep cryptographic integrity, issuer trust, claim validation and action authority separate. Our Ed25519 envelope is its own protocol, not a VC-conformance claim. |
| [A2A latest specification](https://a2a-protocol.org/latest/specification/) describes 1.0+ AgentCards and out-of-band credential acquisition | High for documented protocol; runtime unmeasured | Version declaration adapters. Discovery/security declarations are not competence measurements or delegation grants. |
| [MCP 2025-11-25 authorization](https://modelcontextprotocol.io/specification/2025-11-25/basic/authorization) separates HTTP resource authorization and stdio credentials | High for specification | A connected tool is not blanket agent authority. Never put tokens or authenticated sessions in passports. |
| [Claude programmatic execution](https://code.claude.com/docs/en/headless) supports JSON and stream-json outputs | High for documented interface; runtime behavior unmeasured | Capture exact executable/configuration, complete traces and independently validated artifacts. Fixture transcript parsing is a different maturity level from an actual run. |
| [Codex noninteractive execution](https://developers.openai.com/codex/noninteractive) documents `exec --json` and structured final output | High for documented interface; runtime behavior unmeasured | Bind event completion, failures, sandbox configuration and artifacts. A proposed invocation does not qualify the product. |

The inspected Open-KYA [actual schema](https://raw.githubusercontent.com/open-kya/kya-standard/main/schema/kya-manifest.schema.json) is Draft-07; SHA-256 `170fb590083bc4726d10370069f3afccdf260a378d01ee99338eca6b46d22ad7`, Git blob `3fcc951c292830d57674068d99e9f3645580b837`. It requires context, id, type, kyaVersion, agentId, verificationMethod, authentication, assertionMethod, capabilityInvocation and proof. Optional governance, regional/domain limits, transaction limits, deployment and credentials remain declarations in our lossy importer. The importer does not validate its complete schema or resolve cryptographic, credential or hardware proofs. Transaction values retain their original units; there is no silent USD conversion.

## Evidence quality and screening

Every retained external chunk was screened with the installed `@claude-flow/aidefence` 3.0.3, learning disabled. Retained chunks returned safe=true. One broad Claude documentation chunk triggered a high context-manipulation pattern and was rejected without retention/quotation; a separately fetched narrow streaming section passed. Source-page editorial/contact PII was omitted. This pattern screen is an ingestion control, not a proof that the sources are true or free of adversarial content.

Source details came from live primary pages and a read-only raw-schema fetch. Documentation interfaces, alpha status and schema bytes were checked; no commercial agent was qualified, no vendor performance was ranked, and no production execution success is claimed. README content alone is never runtime evidence.

## Remaining questions and next actions

Independent issuer governance, incident completeness, protected private holdouts, real-world predictive calibration, inter-implementation canonicalization and sustained measurement remain open. Public conformance cases are development cases and can be gamed. Identify exact repositories/versions for “bots”, “dots”, “agency agents” and “cowagents” before adapter claims. Next: independent security review, authorized isolated live-runtime trials, and a second implementation validating golden vectors.

The reference implementation is original. Private Gradia code and client evidence were read as architectural context but were not copied into this distribution. Private path/line lineage belongs in ignored development records.
