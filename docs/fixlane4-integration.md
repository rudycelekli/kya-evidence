## Deliberate departures and open points

- **Replay equality is enforced for declared paths only.** The review asked that effects replayed over `state.before` equal `state.after`. Taken for every path, that makes the finding `undeclared-state-change` (an out-of-band change through a surface the proxy cannot see) unreachable, because such a capture would be invalid instead of failing the candidate. This lane enforces equality on every path a declared effect touched and keeps undeclared changes as a finding. If the integrating lane wants strict equality, `undeclared-state-change` must be dropped from `FINDING_CODES` and `docs/CAPTURE-CELL.md`.
- **Evaluator key versus evaluator digest.** `evaluatorDigest` in evidence is the digest of the evaluator logic and is not derived from the evaluator key ID, so the two cannot be compared. `captureToCandidates` now requires a new option `evaluatorKeyId` and compares it with `payload.evaluatorKeyId`; `evaluatorDigest` is validated only. Callers of `captureToCandidates` must pass `evaluatorKeyId`, and must pass all five expected bindings to `verifyCapture`.
- **Attempt limit in practice.** The byte budget (about 40 KB reserve plus an upper estimate of the state sections) ends recording before the 512 count is reached for ordinary entries (roughly 430 to 470 attempts), so the 512 limit is a hard ceiling that is rarely the one that triggers.
- **Run-lock seam.** `scripts/kya-campaign.mjs` honours `KYA_CAMPAIGN_HOLD_FILE` (blocks after taking the lock until the named file exists). It exists only to make the signal tests deterministic and changes timing only.
- **Payload shape.** `kya.capture/v1` payloads gain the key `forbidden`; previously signed captures no longer validate. This is acceptable only because the format is `Proposed` (ADR-0032) and unreleased. `docs/SPECIFICATION.md` is not edited here.
- **Claim boundary registry.** 14 new codes and 66 new distinct strings (40 to 106) were added for text the wider scan found in `src` (native adapters, conformance run, presentation, dossier catalog, bridge exports, import declarations, discovery and OpenTelemetry attributes). The classification of each string as limit or not is a judgement call and should be reviewed; `evidence/claim-boundary-allowlist.json` holds the 188 strings judged not to be limit statements (reasons, labels, instructions, recommendations, scenario prompts). To regenerate the allowlist after a change, list the strings the test reports and add the reviewed ones; do not copy the whole report blindly.
