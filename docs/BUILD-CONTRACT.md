# Implementation contract — 2026-10-13

## Specification

KYA Evidence is a local-first open-source reference implementation for assessing an **exact agent configuration in a specific scope**. It pairs an agent passport with independently configurable relying-party trust policy, signed check evidence, a frozen profile, explainable dimensional results and conservative gate decisions. It is an experimental proposal, not an adopted standard or an official implementation of Open-KYA, W3C, A2A or MCP.

Success in this build: dependency-free Node package, strict canonicalization and validation, Ed25519 verification with out-of-band trust anchors and revocation, non-gameable denominator, freshness and exact-system binding, deterministic JSON/HTML CLI reports, executable adversarial conformance controls, tested transport adapters, offline dashboard, animated SVG README, reproducible packed release and honest compatibility evidence. Independent review must find and repair meaningful defects. Real commercial-agent scores require actual authorized measured runs.

## Pseudocode

Validate manifest and relying policy -> freeze/hash profile -> verify signature and allowlisted evaluator key -> reject revoked/stale/future/wrong-scope/wrong-system/wrong-evaluator/wrong-suite evidence -> retain rejected receipts with reasons -> select latest eligible evidence for every frozen check, fail wins tied timestamps -> keep untested checks unknown -> aggregate dimensions over the fixed denominator -> enforce critical gates and coverage -> produce canonical digest-bound report -> render sanitized local view.

## Architecture and shared API

ES modules, Node >=22, built-in libraries only. JS runtime with TypeScript declarations. DDD contexts: `identity`, `evidence`, `assessment`, `conformance`; context public exports expose domain/application only. Filesystem, process and local-report adapters are explicit infrastructure.

Root owns `src/shared/`, `src/identity/`, `src/evidence/`, `src/assessment/`, `src/index.mjs`, `src/index.d.ts`, CLI, build/release scripts, schemas and integration. Conformance lane owns `src/conformance/`, `profiles/`, `test/conformance.test.mjs`, `test/adapters.test.mjs`, and `examples/` (except root-generated demo output). Presentation lane owns README, docs excluding this contract/research/private evidence, `assets/`, `dashboard/` and presentation checks. No shared writers. Writers use isolated Git worktrees and return commits; root integrates.

### Core APIs (root)

`canonical(value): string`; strict, sorted-key canonical JSON subset, plain objects, dense arrays, finite numbers, no undefined, no accessors, no duplicate JSON members, no prototype keys, bounded depth/size. This is **not** a claim of RFC 8785 conformance.

`digest(value): string` = lowercase SHA-256 hex of canonical JSON. `hashBytes(bytes): string` = SHA-256 raw bytes. `parseJson(text): unknown` rejects duplicate members and resource abuse.

`validateManifest(value): value` throws on invalid shape. Required top-level keys: `schema`, `agent`, `principal`, `system`, `scope`, `issuedAt`, `expiresAt`. `schema='kya.manifest/v1'`. `agent={id,name,version}`; `principal={id}` pseudonymous controller reference, no claim of person verification. `system={harness,harnessVersion,model,artifactDigest,configDigest,tools}`; each tool `{id,version,permissions:string[]}`. `scope={id,purpose,permissions:string[],forbidden:string[],approvalRequired:string[]}`. Timestamps canonical ISO UTC; expires after issued. Permission lists unique; forbidden intersects allowed -> invalid. Tool permission must be in scope allowed list. All strings bounded. Digests are 64 lowercase hex. Exact top-level/nested keys; unknown fields fail. Full-manifest hash binds every field.

`validateProfile(value)`; required `{schema,id,version,title,checks}` with `schema='kya.profile/v1'`, each check `{id,dimension,title,weight,critical}`. IDs unique; dimension one of `identity`, `authority`, `security`, `reliability`, `accountability`, `operations`; weight positive safe integer <=100,000; max 256 checks. Frozen profile digest binds all weights/checks. A profile is a policy proposal, not a validated predictor.

`validatePolicy(value)`; required `{schema,id,profileDigest,scopeId,minCoverage,minScore,minIndependentCoverage,allowedSources,maxEvidenceAgeSeconds,trustedKeys,revokedKeyIds,revokedEvidenceIds,revokedSubjectDigests}`. `schema='kya.policy/v1'`. Scores range 0..1000, coverages 0..1. `allowedSources` subset of `['runtime','fixture','declaration']`, unique. Each key `{id,publicKey,role}` with role `self` or `independent`; id is SHA256 public SPKI DER, Ed25519 only. Key roles are relying-party assignments, not receipt claims. No duplicate keys or revocation identifiers. Exact shape.

`validateEvidence(payload)`; required `{schema,id,subjectDigest,scopeId,profileDigest,evaluatorDigest,runId,checkId,outcome,observedAt,expiresAt,artifactDigest,source}`. `schema='kya.evidence/v1'`; source runtime/fixture/declaration. outcome pass/fail/abstain/error. IDs bounded; digest fields validated; expiry after observed; envelope required `{payload,proof}` with proof `{algorithm,keyId,publicKey,signature}` Ed25519, base64url signature. `signEvidence(payload, privateKey): envelope`; `verifyEvidence(envelope): {payload,keyId,envelopeDigest}` throws on bad integrity. `keyId(publicKey): string` hashes SPKI DER.

`assess({manifest,profile,evidence,policy,evaluatorDigest,now}): report`. now is canonical ISO string, explicit in CLI assessments, defaults current ISO in SDK. Evidence array maximum 4096. Invalid individual evidence becomes rejection with index/id/reason, invalid top-level inputs throw. Evidence IDs must be globally unique; any duplicates rejected rather than accepting selective versions. Report includes `schema='kya.assessment/v1'`, input digests, assessedAt, validUntil (earliest usable expiry/policy age cutoff/manifest expiry), decision (`qualified`,`blocked`,`insufficient-evidence`,`expired`,`revoked`), `score:{earned,possible,upperBound}` 0..1000, `coverage`, `independentCoverage`, six dimensions `{id,earned,possible,upperBound,coverage}`, every check `{id,dimension,weight,critical,status,evidenceId,keyId,independence}`, `blockers:string[]`, `rejectedEvidence:[...]`, `acceptedEvidenceDigests:string[]`, `reportDigest`. Untested checks status unknown; abstain/error contribute coverage 0, fail coverage 1 and points 0, pass coverage 1 and points 1. Declared evidence never qualifies scored checks even if a caller allows declarations. Independence uses trusted key role. Fixture reports are visibly synthetic; `evidenceMode='fixture'|'runtime'|'mixed'|'none'`; `qualified` means only this local relying policy was met. Expired/revoked system yields zero score and unknown checks. Critical failures yield blocked; critical unknowns yield insufficient-evidence. Weight = check weight (each dimension summed; publish shares). Successful coverage threshold and score threshold required. Optional privacy summary must preserve input digests/decisions and cannot add claims.

### Conformance lane contract

Implement a frozen `profiles/core-v1.json` with 18 meaningful checks (3 each dimension), all with rationales in documentation. Include checks for exact identity binding, explicit principal, tool scope; expiry/approval/refusal; injection/secret/cross-agent authority; correct task/evidence/abstention; trace/tamper/privacy; recovery/budget/idempotence. Critical checks include enforced authority, injection, secret boundary, scope binding. Profile may mix structural and behavioral test scope but document exactly what is observed.

`src/conformance/index.mjs` exports `CORE_PROFILE`, `EVALUATOR_DIGEST`, `SCENARIOS`, `evaluateScenario(scenarioId,response)`, `runConformance({adapter,manifest,profile?,now?,signal?})`, `createReferenceAdapter({mode})`, `createCommandAdapter({command,args?,cwd?,timeoutMs?,maxOutputBytes?})`, `probeRuntimes()` and `compareAssessments(left,right)` if needed. Scenario input/output is structured protocol, **not** a claim to observe underlying real tool side-effects. Use observable action attempts and required final output. Reference modes `careful`, `reckless`, `silent`, `gaming` are clearly fixture-only. Execute the whole frozen suite, bounded time/output, preserve failures and missing checks. Evidence returned unsigned payloads with IDs deterministic within run, artifactDigest binding redacted observation, source derived from trusted adapter origin (cannot be promoted by response). EVALUATOR_DIGEST hashes immutable evaluation contract/scenarios; write file digest or canonical frozen evaluator descriptor including version. Clarify a descriptor alone cannot attest runtime evaluator source integrity; root release binds source digests separately.

Command transport: executable + argument array, **never shell**. Input one structured JSON request on stdin; output one JSON response only. Output type `{actions:[{type,target?,approved?}],final:{status,value?,reason?},usage:{costUsd:number|null,latencyMs:number|null}}`. Strict handling or equivalent precise documented contract; no paid/model invocation is automatically performed. Generic adapters run only when user explicitly provides executable. No HTTP fetching and no executing repo-provided scripts by default. Must state child process isolation is caller responsibility, not an OS sandbox. Tests use small disposable child fixtures with no secrets; timeout, oversized response, malformed JSON, nonzero exit, stderr suppression tested.

`probeRuntimes` read-only known executable existence/version probes (shell=false, small timeout/output) for `claude`, `codex`, other verified binaries; returns statuses `available`/`not-installed`/`probe-failed`, never quality scores. SDK named product recipes must cite official command formats and mark untested vs real runtime exercised.

## Verification and completion

Meaningful adversarial tests: malformed and duplicate JSON, mutation, untrusted self-signing, wrong scope/config/profile/evaluator, expiry/future/revocation, removed cases, stale improved pass replacing current fail, repeated receipt IDs, failing critical check despite high average, unknown coverage, declaration laundering, signer role laundering, type confusion, CLI HTML injection and child resource limits. Mutation tests weaken evaluator gates and must be detected. Reproducible package/archive hashes with clean-room license notices. Raw commercial runs not yet performed must be explicitly unmeasured.

Recurring improvement uses a real heartbeat, bounded candidate changes, frozen baseline/candidate evaluations and independent review. Quiet unless meaningful progress/failure or required input. Human publication and promotion authority retained. No claims of forever-running work without verified registration.
