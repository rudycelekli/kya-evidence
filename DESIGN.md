# Design context

An engineer reads the README beside a terminal on a daylight laptop, then prints an assurance report for review. Warm paper, dark ink and restrained forest green keep long explanations readable. Dark system preferences receive a separate readable SVG palette.

## Existing visual system

The existing hero and evidence-flow SVGs establish paper surfaces, forest ink, monospace evidence labels, ruled separators and amber uncertainty markers. The dossier uses Georgia display type, system body text and monospace digests. No external fonts or tracking assets are loaded.

## Tokens and structure

Paper: #f4f2eb or #e9f2e9. Ink: #173c32. Secondary ink: #4f6659. Verified structured-response accents: #256c4b. Unmeasured evidence: #d8a23f with explicit text. Hairline separators define reading order. Avoid repeated equal cards; use a narrative diagram, continuous evidence ledger and expandable check details.

## Motion contract

One illustrated evidence-flow traveler connects records to response replay, supported strengths and persistent unknowns. Animate transform/opacity only. Preserve every substantive label when motion is disabled. No per-frame JavaScript, flashing alerts or simulated live-status claims. Keep SVG assets small and self-contained; frame-rate performance remains unmeasured.

## Report contract

State the relying-policy decision and evidence source first. List supported structured-response strengths separately from signed claims. Keep failures, root-cause uncertainty, blind spots, coverage and reported-cost completeness visible. Every standalone presentation remains unauthenticated and requires reconstruction from frozen authorized inputs.
